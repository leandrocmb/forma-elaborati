Autodesk Platform Services (APS) — OAuth 2.0
Questa app si connette a Forma tramite le API APS. Crea un'applicazione su APS Developer Portal con scopes data:read data:write e un Callback URL che punti a questa pagina. Il token viene ottenuto con flusso 3-legged (Authorization Code).

⚠ Per sicurezza, non inserire mai il Client Secret in un'app front-end pubblica. In produzione usa un backend proxy (es. Azure Function, Node.js) per scambiare il token.
